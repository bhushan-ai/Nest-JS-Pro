# NestJS Learning Repository 🚀

This repository contains my **practice projects and exercises while learning NestJS**, a modern backend framework for Node.js.

NestJS is a framework designed to build **scalable and maintainable server-side applications using TypeScript and Node.js**. It provides a structured architecture with concepts like modules, controllers, and services to help developers build clean backend systems. ([NestJS Documentation][1])

# 📂 Project Structure (Example)

Typical NestJS structure used in this repository:

```
src/
 ├── app.controller.ts
 ├── app.service.ts
 ├── app.module.ts
 ├── modules/
 │    ├── users
 │    ├── auth
 │    └── products
 └── main.ts
```

Main concepts:

* **Module** → organizes application features
* **Controller** → handles incoming requests
* **Service** → contains business logic

# 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/bhushan-ai/Nest-JS-Pro.git
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the development server

```bash
npm run start:dev
```

Server runs on:

```
http://localhost:3000
```
